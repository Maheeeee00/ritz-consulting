# Ritz Consulting – Demo Website

A light, highly animated multi-page website for an Australian accounting & advisory firm.
Pure HTML + CSS with a small vanilla JS file — no build step.

- `framework.html`
- `team.html`
- `faq.html`
- `contact.html`
- `404.html`

## Structure
```
assets/css/style.css   shared styles & animations
assets/js/main.js      scroll reveals, counters, sticky nav
vercel.json            clean URLs (/about instead of /about.html)
```

## Deploy
1. Push this folder to a new GitHub repository.
2. In Vercel: **Add New → Project → Import** the repo.
3. Framework preset: **Other**. Leave build command and output directory empty.
4. Click **Deploy**.

Demo content only — replace phone numbers, addresses, team members and testimonials before going live.
Photos are loaded from Unsplash.
